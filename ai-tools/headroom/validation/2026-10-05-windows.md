## Advertencias investigadas

`doctor --json` devolvió código **1**, con proxy y versión saludables. Avisó ausencia de routing global, presupuesto, datos en el proceso recién iniciado y Kompress no lista. El routing de las CLI envueltas fue comprobado; no se forzó routing global para ocultar avisos.

Warmup informó SmartCrusher, CodeAware y Tree-sitter cargados. Kompress quedó `source_status=deferred`: su camino ML no fue comprobado. La prueba MCP usó el detector Python de Windows, conservando el fallback seguro de Magika/ONNX.

No hizo falta un workaround TLS. `doctor --network` no existe en 0.39.1. Los logs advirtieron que Headroom no establece ACL de Windows; no se activó logging completo de mensajes ni exportadores externos.
